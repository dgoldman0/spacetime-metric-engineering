# Development record for the two-column revision (2026-09-26)

Kept for provenance. None of these files is used by the build.

- `layout-prototype/`: the first test page of the two-column layout and its renders.
- `figure-tests/`: small test documents used to debug the figure preamble and
  the warp-bubble figure, including `ch01-warp_attempt1.tex`, the first version
  of that figure (wall parameter 8, before the switch to 4).
- `preview-renders/`: renders of the figures made while iterating on them,
  including early versions with overlapping labels and the broken first render
  of the design loop.

The single-column draft that preceded this revision is in
`../2026-09-26_rev0_single-column/`.
